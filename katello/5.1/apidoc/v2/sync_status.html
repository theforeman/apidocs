GET /katello/api/sync_status/poll
Poll sync status for specified repositories

Examples

GET /katello/api/sync_status/poll
200
[
  {
    "id": 367202338,
    "product_id": 785257261,
    "progress": {},
    "state": "Syncing Complete.",
    "raw_state": "stopped",
    "start_time": "less than a minute ago"
  }
]

Params

Param name Description
repository_ids
required

List of repository IDs to poll

Validations:

  • Must be an array of any type
organization_id
optional

ID of an organization

Validations:

  • Must be a number.
>>>

POST /katello/api/sync_status/sync
Synchronize repositories

Examples

POST /katello/api/sync_status/sync
{
  "repository_ids": [
    367202338
  ],
  "organization_id": 114267492,
  "sync_status": {
    "repository_ids": [
      367202338
    ],
    "organization_id": 114267492
  }
}
200
[
  {}
]

Params

Param name Description
repository_ids
required

List of repository IDs to sync

Validations:

  • Must be an array of any type
organization_id
optional

ID of an organization

Validations:

  • Must be a number.
>>>

DELETE /katello/api/sync_status/:id
Cancel repository synchronization

Examples

DELETE /katello/api/sync_status/367202338
{
  "sync_status": {}
}
200
{
  "message": "Sync canceled"
}

Params

Param name Description
id
required

Repository ID

Validations:

  • Must be a number.
